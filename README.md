## Description
Watchlist app that can be used with the [movie-api](https://github.com/Ggwepq/SIA-Restful-Api/tree/movie-api).
Just run the api and the app simultaneously to make them work.

Features
- View user's watchlists
- View and watch movie from the watchlist
